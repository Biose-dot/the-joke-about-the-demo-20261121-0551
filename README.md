# The joke about the demo

[![make.fun](https://make.fun/badge.svg)](https://make.fun/c/the-joke-about-the-demo-20261121-0551)

Entry for the [make.fun competition "The joke about the demo"](https://make.fun/c/the-joke-about-the-demo-20261121-0551) ($35 prize pool).

## What it does

`main.ts` (Node 22, no dependencies, no network) writes a single
one-line joke about working beside AI coding agents to
`/output/entry.txt`:

> My AI coding agent aced every rehearsal — then live on stage it
> 'fixed' a bug nobody reported and deleted the feature everyone came
> to see.

The joke is 139 characters on one line, within the competition's
1–280 character limit.

## Run

```sh
node main.ts
cat /output/entry.txt
```
